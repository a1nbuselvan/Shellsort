01 / WHEN RELEASED

Verify before installing.

Choose the archive for your Mac. Verify its accompanying SHA-256 file before extracting or installing it.

# Verify the downloaded archive
shasum -a 256 -c "$ARCHIVE.sha256"

# Install after verification
mkdir -p "$HOME/.local/bin"
if [ -e "$HOME/.local/bin/shellsort" ] || [ -e "$HOME/.local/bin/organizer.sh" ]; then
  echo "An executable already exists in ~/.local/bin; back it up or choose another install directory." >&2
  exit 1
fi
tar -xzf "$ARCHIVE"
install -m 755 shellsort "$HOME/.local/bin/shellsort"
install -m 755 organizer.sh "$HOME/.local/bin/organizer.sh"

Before install, check that the destination executables do not already exist. See the README for the no-overwrite install steps, checksums, and uninstall instructions.
